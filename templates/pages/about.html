About the Web Scrapers

Overview

This application provides a collection of web scrapers designed to extract product data from various food service and distribution websites. The scrapers are built using Python with Selenium and BeautifulSoup for reliable data extraction.

Features

  • ✓ Extract product details including names, prices, and descriptions
  • ✓ Handle pagination and dynamic content loading
  • ✓ Export data to CSV format for easy analysis
  • ✓ Support for multiple vendors and websites
  • ✓ Web interface for easy access and control

How to Use

Accessing Scrapers

  1. Navigate to the Scrapers page
  2. Click on the vendor's button to access a specific scraper
  3. Select the category. Some scrapers support choosing "All"
  4. Click the checkbox of the step you want to run
  5. Monitor the progress in the browser
  6. Results are saved to a csv file.

Requirements

  • Python 3.8+
  • Chrome or Firefox browser
  • ChromeDriver or GeckoDriver (for Selenium)
  • Required Python packages (see requirements.txt)
  • Ability to run Django on a server

Process

  • Collect a list of top categories. These go as deep as possible. The categories are stored in json and hard coded into the scraper class.
  • For each category, collect a list of products. The products are stored in a csv file with a file name normally in the format of [category]_product_urls.csv
  • For each product, collect the details. The details are stored in a csv file with a file name normally in the format of [category]_product_data.csv

Website Format

Most Common

Most websites hava a navigation with 1 to 3 levels of taxonomy.

Navigating to a category provides a paged list of products.

Product details are accessed by clicking a product in the list. The scraper stores the list of product urls which it visits during the process products step.

Less Common

Website with a page that lists all the products with no detail page.(Not Yet Implemented)
